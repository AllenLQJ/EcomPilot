## 3. 未完成项与已知缺陷
- EcomNLU / EcomRAG / EcomOps 为确定性桩；AC-TX-04 中"进程重启后从检查点恢复"不在本交付范围。
- MCP 工具层非独立协议服务；A2A 为自定义 HTTP 协议（`contracts/agents.md`），非官方 A2A SDK。
- 真实缺货不落 `CLOSED_OUT_OF_STOCK` 订单（见决策 2）。
- 乐观锁 20 用户同 SKU 并发时允许个别 503 `CONCURRENT_VERSION_CONFLICT`（符合规格）；本次 5 轮压测未出现测试失败。
- 同一子项售后被驳回后不能再次提交（唯一键 `order_id,order_item_id`）。
- 售后候选包含 PAID_SIMULATED（按路线图），但确认只接受 FULFILLED。
- 开发令牌端点仅在 `ECOMPILOT_DEV_TOKENS=1` 时存在，生产必须关闭并替换 `JWT_SECRET`。
